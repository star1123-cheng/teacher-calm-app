# 寧靜模式規格（M2）

## 時光倒數
- 設定：起點日、終點日。預設起點＝今天，終點＝今年 12/31。可隨時修改。
- 顯示：剩餘天數（大字）加進度條（已過 %）。
- 到期：顯示「已完成」加一句收尾語，並出現【設定新的倒數】按鈕。
- 驗證：起點晚於終點時擋下並提示修正，不得出現負數。

驗收：
- [ ] 首次開啟預設值正確
- [ ] 修改日期後即時更新，重開仍保留
- [ ] 起點 > 終點時無法儲存並有提示
- [ ] 終點當天顯示 0 天，隔天顯示「已完成」與按鈕
- [ ] 進度條 0% 到 100%，不溢出

## 一日一句
- 句庫：使用者匯入 CSV（欄位：句子、作者、書名、頁碼，見 data-storage.md）。另有內建原創句庫（seed/quotes-original.csv，作者欄為「原創」）。
- 輪替：隨機、一輪不重複。作家句優先，作家句全部出現過一輪後才補原創句；整體輪完後重新洗牌。
- 同一天重複開啟看到同一句（當天結果存起來，隔天才換）。
- 顯示：句子、作者、書名（有才顯示）、頁碼（有才顯示）。原創句顯示「原創」。
- 匯入：選檔後預覽筆數與前 3 筆，確認才寫入；重複句子略過；錯誤列報告行號。

驗收：
- [ ] 匯入範本檔成功，筆數正確
- [ ] 含逗號與換行的欄位（雙引號包起來）解析正確
- [ ] 一輪內不重複；作家句先於原創句
- [ ] 同日重開同一句，隔日換句
- [ ] 沒有匯入任何作家句時，只輪原創句
- [ ] 欄位缺漏（無書名、無頁碼）時版面不破

## 工作紀要
- 欄位：日期（預設今天）、分類標籤（教學／行政／網管）、內容、完成勾選。
- 功能：新增、編輯、刪除、勾選、依分類與完成狀態篩選、依日期倒序。
- 匯出：「複製成文字」格式 `YYYY-MM-DD [分類] 內容`，已完成的加 `✓`。

驗收：
- [ ] 新增、編輯、刪除後重開仍保留
- [ ] 篩選正確
- [ ] 複製文字格式正確，可貼進公文或週報
- [ ] 內容為空時不可新增
