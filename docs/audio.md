# 白噪音規格（M3 單軌、M5 混音）

## 音源
- （2026-10-09 依使用者決定移除 Web Audio 合成噪音，只播放自備音檔。）
- 音檔（使用者自備）：放在 `assets/audio/`，檔名如 `rain.mp3`、`sea.mp3`、`forest.mp3`、`cafe.mp3`，以 `assets/audio/manifest.json` 登記顯示名稱與檔名，可增減。
- 格式：mp3，白噪音單檔 1 到 2 分鐘，可無縫循環（頭尾相接不爆音）。總量 ≤ 20 MB；2026-10-09 白噪音裁成 90 秒，目前 6 檔共約 13 MB。背景音樂同一首循環播放。
- 背景音樂（2026-10-09 新增）：manifest 的 `bgm` 陣列（AI 生成曲）。不分模式，開 App 後第一次點畫面隨機播一首，切換模式時隨機換曲，一首播完接著隨機下一首；播白噪音時暫停，白噪音停止後恢復；設定頁可關閉。
- 授權：只使用可商用或 CC0 素材，由使用者自行確認。

## 功能
- 播放、暫停、音量。瀏覽器需使用者手勢才能開始播放。
- 定時關閉：15、30、60 分鐘或不定時，結束時淡出約 3 秒。
- 混音（M5）：最多 2 軌，各自音量；預設關閉，於設定開啟。
- 音檔由 service worker 快取，離線可播。

## 已知限制
iPhone 螢幕鎖定或切換 App 後，音訊可能被系統暫停，不承諾背景播放；於設定頁以文字說明。

驗收：
- [ ] 多個音檔可切換、音量可調
- [ ] 音檔可循環，接縫無明顯爆音
- [ ] 定時關閉準時淡出停止
- [ ] 斷網可播已快取音檔
- [ ] 混音關閉時只能單軌；開啟後第 3 軌被拒絕並提示
- [ ] 缺少音檔時顯示說明文字，不報錯
