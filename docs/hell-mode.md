# 地獄模式規格（M3 骨架、M5 收尾）

## 彩蛋切換
- 寧靜模式的【我很快樂】按鈕：5 秒內連點 3 次進入地獄模式。超過 5 秒未達 3 次則計數歸零。（2026-10-10 由 3 秒 5 次放寬）
- 第 2 次起給微提示（按鈕輕微抖動）。尊重 `prefers-reduced-motion`，開啟時改為無動畫提示。
- 進入地獄模式有「燒幕」轉場（2026-10-10 新增，見 js/burn.js）：宣紙上浮現黑色行書「我常在開心的時候感到難過／因為我不知道可以開心多久」，接著畫面由下往上燃燒，像燒掉布幕一樣揭開地獄模式。點一下可略過；減少動態時改為直接切換。回寧靜模式維持約 1 秒翻面。
- 地獄模式有【我真的累了】按鈕，點一次回寧靜模式。
- 模式不持久化，每次啟動一律從寧靜模式開始。

驗收：
- [ ] 5 秒內 3 次必定切換；第 6 秒才點第 3 次不切換
- [ ] 第 2 次起有提示；計數歸零後重新計
- [ ] 切換與返回都有轉場，減少動態時無動畫
- [ ] 重新整理後回到寧靜模式

## 首次設定
第一次進地獄模式才跳出表單：預計退休日、學歷、目前薪級、加給開關與金額。可跳過（以示意預設值顯示並標示「範例」），之後可從設定修改。細節見 salary.md。

## 退休倒數
- 顯示剩餘天數，必要時顯示「約 N 年 M 個月」。
- 退休日早於今天：顯示「已退休，恭喜」，不顯示負數。

## 毒雞湯（M5）
- 來源：seed/toxic-soup.csv（240 句，單欄「句子」）。輪替規則同一日一句（隨機、一輪不重複、同日同句），另有【再來一句】按鈕可抽下一句。
- 尺度：輕度自嘲到中度黑色幽默。不提真實人物與學生。
- 薪水區固定標示：「不含年終、考績獎金與扣款，僅供娛樂」。

驗收：
- [ ] 毒雞湯輪播符合規則，再來一句不重複
- [ ] 標示文字固定出現在薪水區
- [ ] 未設定資料時顯示範例標示，不報錯
