# 地獄模式規格（M3 骨架、M5 收尾）

## 彩蛋切換
- 寧靜模式的【我很快樂】按鈕：3 秒內連點 5 次進入地獄模式。超過 3 秒未達 5 次則計數歸零。
- 第 3 次起給微提示（按鈕輕微抖動）。尊重 `prefers-reduced-motion`，開啟時改為無動畫提示。
- 切換有約 1 秒轉場（畫面變暗變紅）。
- 地獄模式有【我真的累了】按鈕，點一次回寧靜模式。
- 模式不持久化，每次啟動一律從寧靜模式開始。

驗收：
- [ ] 3 秒內 5 次必定切換；第 4 秒才點第 5 次不切換
- [ ] 第 3 次起有提示；計數歸零後重新計
- [ ] 切換與返回都有轉場，減少動態時無動畫
- [ ] 重新整理後回到寧靜模式

## 首次設定
第一次進地獄模式才跳出表單：預計退休日、學歷、目前薪級、加給開關與金額。可跳過（以示意預設值顯示並標示「範例」），之後可從設定修改。細節見 salary.md。

## 退休倒數
- 顯示剩餘天數，必要時顯示「約 N 年 M 個月」。
- 退休日早於今天：顯示「已退休，恭喜」，不顯示負數。

見 salary.md（M4）。

## 毒雞湯（M5）
- 來源：seed/hell-soup.csv。輪替規則同一日一句（隨機、一輪不重複、同日同句），另有【再來一句】按鈕可抽下一句。
- 尺度：輕度自嘲到中度黑色幽默。不提真實人物與學生。
- 薪水區固定標示：「不含年終、考績獎金與扣款，僅供娛樂」。

驗收：
- [ ] 毒雞湯輪播符合規則，再來一句不重複
- [ ] 標示文字固定出現在薪水區
- [ ] 未設定資料時顯示範例標示，不報錯
