## 已定案的 UI 決策
1. 日夜切換（僅寧靜模式）：07:00（含）到 18:00（不含）為白天，其餘為夜晚；以裝置本地時間判斷。
2. 斷點：768 px 以下用手機版圖與排版；769 px 以上用電腦版圖與排版。iPad 直式沿用手機排版（內容區最大寬 560 px 置中），1024 px 以上用電腦版（假設，待核對）。
3. 手機版寧靜模式：整頁 100dvh 不捲動。上半（約 46%）由上而下為時光倒數、一日一句；下半（約 46%）左右排列，左工作紀要、右白噪音；最底一小列為按鈕「完成今天工作了，我好快樂」（即【我很快樂】）。
4. 手機版地獄模式：上方約 2/3 為退休倒數與薪水計數（特大字）；下方約 1/3 為毒雞湯抽卡，點擊出彈窗；最底一小列為【我真的累了】（此列為假設）。
5. 電腦版有自己的排版：
   - 寧靜：兩欄。左欄時光倒數＋一日一句，右欄工作紀要＋白噪音，最底一列置中按鈕。
   - 地獄：左欄退休倒數＋薪水計數，右欄抽卡大卡片，最底一列置中按鈕。
6. 互動彈窗：
   - 圓環計數彈出 → 時光倒數（電腦版改為置中對話框）。
   - 翻面面板 → 模式切換。
   - 抽卡彈窗 → 底部升起面板加卡片翻開（假設）。
7. 緩動曲線修正：原網路提示詞的 `(.2,7.2,1)` 與 `(.2,.7,2,1)` 為錯誤格式，一律改用 `cubic-bezier(.2, .7, .2, 1)`（假設原意）；翻面用 `cubic-bezier(.3, .7, .2, 1)`。
8. 翻面切換不是單擊：寧靜模式 3 秒內連點【我很快樂】5 次才翻面，第 3 次起微提示；地獄模式點【我真的累了】翻回；每次啟動從寧靜模式開始。
9. 毛玻璃浮層暫不採用（與圓環重複、手機效能風險）；之後可考慮用在地獄模式的「12 個月已領薪水」。

## 完整步驟

### 階段一：準備
1. 確認帳號為 Pro 以上，用電腦瀏覽器開 claude.ai/design。
2. 依上方檔名整理好圖片。
3. 備好下方提示詞一到八。

### 階段二：靜態版面（先不加動畫）
4. 建立新專案，選「高擬真 mockup」，不套設計系統。
5. 上傳寧靜模式手機版白天與夜晚兩張圖，貼提示詞一（手機寧靜版面）。
6. 若它反問，回答：手機寬度 390 px、離線 PWA、系統中文字體、不用外部函式庫、背景圖原樣使用。
7. 貼提示詞二（日夜切換），用預覽切換鈕檢查白天與夜晚兩組的文字對比。
8. 檢查：上下排與左右排是否正確、整頁不捲動、卡片不遮住背景主視覺。
9. 修改規則：整體版面用聊天框，單一元件的間距、字級用行內留言。
10. 上傳地獄模式手機圖，貼提示詞三（手機地獄版面），重複檢查。

### 階段三：電腦版
11. 手機版兩個模式都定稿後，上傳電腦版圖片。
12. 貼提示詞四（電腦寧靜版，含日夜）與提示詞五（電腦地獄版）。
13. 檢查 1440、1280、1024、769 px 四個寬度。

### 階段四：加動畫（一次一個）
14. 提示詞六：圓環計數面板（時光倒數）。
15. 提示詞七：抽卡彈窗（地獄模式）。
16. 提示詞八：翻面切換（模式切換）。
17. 每個都檢查：曲線是否為 `cubic-bezier(.2, .7, .2, 1)`、連點 5 次才翻面、減少動態效果時直接顯示結果。
18. 工作紀要與白噪音面板只留空殼。

### 階段五：匯出與交接
19. 在畫面找匯出或分享選單，優先選能取得 HTML／CSS／JS 原始碼或交給 Claude Code 的選項。
20. 專案建立 design/ 資料夾，放入匯出檔、全部背景圖，與六張對照截圖：calm-mobile-day、calm-mobile-night、calm-desktop-day、calm-desktop-night、hell-mobile、hell-desktop。
21. 先照原交接包的開場提示詞完成 M1，不要把設計稿一起塞給 M1。

### 階段六：套版（M1 完成後，開新對話）
22. 貼提示詞九（UI 套版），在手機與 iPad 實測，特別看翻面閃爍、iPhone 底部工具列遮擋、動畫卡頓、日夜切換在 07:00 與 18:00 前後是否正確。

### 提示詞二：寧靜模式日夜切換

### 提示詞六：時光倒數圓環面板
```
請為「時光倒數」做一個底部圓環彈出面板（純 HTML／CSS／JavaScript，不用函式庫，手機直式優先）。

觸發：點擊首頁的時光倒數卡片。
資料：起點日、終點日（YYYY-MM-DD）。剩餘天數＝終點日減今天（以本地日期 0 點計算，最小 0）。剩餘比例＝剩餘天數 ÷ 總天數，限制在 0 到 1。
- 終點日已過：圓環為空，中心顯示「已完成」，並提供「重設」按鈕。
- 起點晚於終點：不開啟面板，顯示錯誤提示。

動畫（皆用 cubic-bezier(.2, .7, .2, 1)）：
1. 背景遮罩：黑色 opacity 0 → 0.4，0.5 秒。
2. 面板：translateY(100%) → 0，0.5 秒，底部加 env(safe-area-inset-bottom)。
3. 面板定位後（transitionend），圓環 stroke-dashoffset 從整圈畫到「周長 × (1 − 剩餘比例)」，1.2 秒，自 12 點鐘方向順時針。
4. 中心數字從 0 滾到剩餘天數，1.2 秒，與圓環同步。用 JS 實作同一條緩動函式，以 requestAnimationFrame 更新，只顯示整數，font-variant-numeric: tabular-nums。

關閉：點遮罩、關閉鈕或 Esc，反向動畫 0.35 秒。
其他：prefers-reduced-motion 時直接顯示最終狀態；開啟時鎖定背景捲動；加 role="dialog"、aria-modal，焦點移入面板。
圓環半徑、粗細、顏色集中成 CSS 變數，並支援 day 與 night 兩組主題色。
```

## 常見卡關
- 背景被重畫：提示詞再強調「這張圖當 CSS 背景原樣使用」。
- 用量不夠：一次只做一個畫面，不要整套一起丟。
- 匯出後樣式跑掉：先在瀏覽器對照截圖，再決定改設計稿或交給 Claude Code 修。
- 夜晚版文字看不清：在提示詞二指定對比 4.5:1，並請它調整夜晚卡片底色。
